# Refutation of Conjecture 1 (Multilayer Transformer Head Count) in Yu et al. (ICLR 2026, arXiv:2510.06662)

- **Conjecture Source**: Penghao Yu, Haotian Jiang, Zeyu Bao, Ruoxi Yu, Qianxiao Li, *"The Effect of Attention Head Count on Transformer Approximation"*, ICLR 2026 ([arXiv:2510.06662](https://arxiv.org/abs/2510.06662) v2, Mar 31, 2026; camera-ready PDF), Conjecture 1 (`Conjecture1`).
- **Domain**: Machine Learning Theory / Transformer Expressivity & Approximation Theory.
- **Verdict**: **FALSE for standard multilayer bidirectional transformer encoders** (where every token issues attention queries and residual connections around attention are present, matching the multi-token generalization of the paper's eq. (4) and the same authors' follow-up `InfoFlow`, `arXiv:2605.17930`). Both constructions use no LayerNorm, all FFN and attention weights/biases in $[-1,1]$, hidden-state norms $\|x^{(\ell)}(s)\|_2 \le 1$ at every layer, and arbitrarily large inverse temperature $\beta = \Theta(T/\epsilon)$ (matching Yu et al.'s own Theorem 2(1), which leaves $\beta > 0$ free and excludes $\beta$ from the FFN parameter count $M$):
  1. **Theorem A (PE + attention residuals + intermediate FFN):** A **2-layer, 1-head** transformer encoder ($L \cdot h = 2$) with $n = 5D + 2$ approximates **arbitrary $D \ge 3$** ($D \le T$) within $\epsilon$ using FFN parameter count $M = O_{d,D}(1/\epsilon^\gamma)$ (**independent of $T$** when $S_i = [T]$).
  2. **Theorem B (NoPE + NoLN + attention residuals + zero intermediate FFNs):** For **every** $L \ge 2$ and $h \ge 1$, an $L$-layer, $h$-head NoPE encoder with $n \le 5L - 1$ approximates **$D = (2L - 1)h > L \cdot h$** (e.g., $L = 2, h = 1, D = 3$ with $n = 9$) within $\epsilon$ using FFN parameter count $M = O_{d,L,h}(1/\epsilon^\gamma)$ (**independent of $T$**).
- **Important Architectural Caveat & Novelty Note**:
  - Yu et al. (`arXiv:2510.06662`) formally define only a single-layer model (with CLS-only querying) and leave the multilayer architecture unspecified. Both Theorems A and B rely on non-CLS tokens issuing queries in intermediate layers and on residual connections around attention. **CLS-only** multilayer models (where only CLS updates) and **residual-free** multilayer encoders are NOT refuted here and remain open.
  - **Novelty:** No prior refutation or resolution of Conjecture 1 was found across `arXiv:2510.06662` v2, the ICLR 2026 camera-ready PDF, the authors' follow-up `InfoFlow` (`arXiv:2605.17930`), citing papers, or OpenConjecture (OpenReview forum was inaccessible due to a bot challenge). Conceptually, the construction is a clean structural observation — non-CLS tokens act as parallel query slots — that Conjecture 1 overlooked for standard multilayer encoders.

## 1. Exact Target and Preliminary Lemmas

- **Explicit target $H_D \in \mathcal{F}_D^{d,T}$ (Lemma 1):** Choose pairwise distinct $x^{(i)} = (\frac{i}{D+1}, \dots, \frac{i}{D+1}) \in (0,1)^d$, $f_i(x) = \frac{1}{d}\|x - x^{(i)}\|_2^2 \in [0,1]$, $S_i = [T]$, $F_0(z) = \sum_{i=1}^D z_i$, $H_D(X_T) = \sum_{i=1}^D \min_{t \in [T]} f_i(x(t))$. This satisfies every hypothesis of Assumption 2 (`assump:target`), and each $f_i$ is approximated within $\delta \in (0, 1/4]$ on $[0,1]^d$ by a 2-layer ReLU FFN $\Psi_{i,\delta} : [0,1]^d \to [0,1]$ with all weights and biases in $[-1,1]$ and hidden width $\le d(\lceil 1/(2\sqrt{\delta})\rceil + 2)$ (via piecewise-linear interpolation of $(u - c_0)^2$ on $N = \lceil 1/(2\sqrt{\delta})\rceil$ knots).
- **Rescaling Lemma (Lemma 2):** Any 2-layer ReLU FFN $\Phi(z)$ with weights/biases in $[-1,1]$ and width $p$ yields an exact $[-1,1]$-bounded realization of $\Phi(\alpha u)$ ($\alpha \ge 1$) of width $p\lceil \alpha \rceil$ by positive homogeneity $\operatorname{ReLU}(w^\top(\alpha u) + b) = \alpha\operatorname{ReLU}(w^\top u + b/\alpha)$ and splitting each neuron into $\lceil \alpha \rceil$ copies.
- **Uniform Two-Sided Softmin Error Bound (Lemma 3):** For nonempty $S \subseteq [T]$, $a_1, \dots, a_T \in [0,1]$, $a_* = \min_{t \in S} a_t$, and logits $\rho(t) = -a_t$ ($t \in S$), $-(a_t+2)$ ($t \in [T]\setminus S$), $-2$ ($t = T+1$), the softmax-weighted average $\tilde{z} = \sum_{t=1}^T w(t) a_t \in [0,1]$ satisfies
  $$\bigl|\tilde{z} - a_*\bigr| \le \frac{T}{e\tilde{\beta}} + (T + 1)e^{-\tilde{\beta}}$$
  (and for $S = [T]$, $\le \frac{T}{e\tilde{\beta}} + e^{-\tilde{\beta}}$, or $\le \frac{T}{e\tilde{\beta}}$ if CLS is excluded from the attention sum).

## 2. Theorem A: $L = 2, h = 1$ with Positional Encoding Solves Arbitrary $D \ge 3$

With $E = n = 5D + 2$, block layout $u = (u_A, u_B, u_C, u_F, u_G, u_H, u_I) \in \mathbb{R}^D \times \mathbb{R}^D \times \mathbb{R}^D \times \mathbb{R}^D \times \mathbb{R}^D \times \mathbb{R} \times \mathbb{R}$, and $c = (11D + 3)^{-1/2}$:
1. **Input embeddings ($t \in [T]$ and CLS $t = T+1$):** $x^{(0)}(t) = c\,\bar{x}^{(0)}(t)$ with $\bar{x}^{(0)}_A(t)_i = -\Psi_{i,\delta}(x(t)) + r_i(t)$ ($r_i(t) = 0$ if $t \in S_i$, $-2$ otherwise), $\bar{x}^{(0)}_B(t) = \mathbf{1}_{t \le D} e_t$, $\bar{x}^{(0)}_C(t)_i = \Psi_{i,\delta}(x(t))$, $\bar{x}^{(0)}_H(t) = \mathbf{1}_{t \le D}$, $\bar{x}^{(0)}_I(t) = 0$; and CLS has $\bar{c}^{(0)}_A = (-2,\dots,-2)$, $\bar{c}^{(0)}_I = 1$, all else $0$. Clearly $\|x^{(0)}(t)\|_2, \|c^{(0)}\|_2 < 1$.
2. **Layer 1 Attention ($h = 1$, $\{0,1\}$ weights):** Queries read Block $B$, keys read Block $A$, values read Block $C$, output writes to Block $F$. For every token $s \in \{1,\dots,D\}$, its query $c e_s$ selects the $s$-th coordinate of Block $A$, retrieving $\tilde{x}^{(1)}_{F,s}(s) = c\,\tilde{z}_s(X_T)$ (within $\delta + \frac{T}{e\tilde{\beta}_1} + (T+1)e^{-\tilde{\beta}_1}$ of $c\bar{z}_s(X_T)$) — all $D$ tasks in parallel with ONE head!
3. **Layer 1 FFN (exact gating, $D$ ReLU neurons):** $F^{(1)}(u)_{G,i} = \operatorname{ReLU}(u_{F,i} + u_{B,i} - c)$ isolates $x^{(1)}_G(s) = c\,\tilde{z}_s(X_T) e_s$ for $s \in [D]$ and $0$ for $s > D$ (including CLS), preserving $\|x^{(1)}(s)\|_2 \le 1$.
4. **Layer 2 Attention ($h = 1$, $\{0,1\}$ weights):** CLS queries Block $I$ against keys in Block $H$ ($\rho^{(2)}(\mathrm{CLS}, t) = c^2\mathbf{1}_{t \le D}$) and reads Block $G$, producing $\tilde{c}^{(2)}_G = \frac{c e^{\tilde{\beta}_2}}{D e^{\tilde{\beta}_2} + (T+1-D)}(\tilde{z}_1, \dots, \tilde{z}_D)$ uniformly close to $\frac{c}{D}\bar{z}(X_T)$.
5. **Layer 2 FFN:** Rescaling by $\alpha_D = D/c$ via Lemma 2 and applying a $[-1,1]$-bounded approximator to $F_0$ yields uniform error $< \epsilon$ with $M = O_{d,D}(1/\epsilon^\gamma)$ parameters (completely independent of $T$ when $S_i = [T]$), refuting Conjecture 1 for every $a_2, b_2 > 0$. $\blacksquare$

## 3. Theorem B: Even NoPE + NoLN + Zero Intermediate FFNs Refutes $L \cdot h \ge D$ for Every $L \ge 2, h \ge 1$

Set $D := (2L - 1)h > L \cdot h$ (e.g., $L = 2, h = 1, D = 3$) and $E = nh \ge (5L-3)h + 2 = 2D + (L-1)h + 2$ ($n \le 5L - 1$; $n = 9$ for $L=2, h=1$). Block layout $u = (u_V, u_M, u_{M'}, u_{\mathrm{cls}}, u_{\mathrm{tok}}, \dots)$ with $c = E^{-1/2}$:
1. **NoPE Embeddings:** $x^{(0)}(t)$ stores $(c\Psi_{1,\delta}(x(t)), \dots, c\Psi_{D,\delta}(x(t)))$ in Block $V$ and $u_{\mathrm{tok}} = c$ (zero dependence on $t$!); CLS stores only $u_{\mathrm{cls}} = c$.
2. **Layers $\ell = 1, \dots, L-1$ (zero intermediate FFNs, $\{-1,0,1\}$ attention weights):** Each head $j \in [h]$ simultaneously serves two distinct retrieval tasks $i_1 = (\ell-1)h + j$ (for query $s = \mathrm{CLS}$) and $i_2 = Lh + (\ell-1)h + j$ (for all input queries $s \in [T]$), using $W_{Q,j}^{(\ell)} u = (u_{\mathrm{cls}}, u_{\mathrm{tok}}, u_{\mathrm{cls}}+u_{\mathrm{tok}}, u_{\mathrm{cls}}+u_{\mathrm{tok}}, 0\dots)$ and $W_{K,j}^{(\ell)} u = (-u_{V,i_1}, -u_{V,i_2}, -u_{\mathrm{cls}}, -u_{\mathrm{cls}}, 0\dots)$. Thus CLS accumulates $Lh$ minima directly while *every* input token $s \in [T]$ stores the **exact same** $(L-1)h$ minima in slots $M_{Lh+1}, \dots, M_D$.
3. **Layer $L$ (final retrieval + piggyback readout):** Head $j$ retrieves the final CLS task $i_1 = (L-1)h + j$ into $M_{i_1}$ AND copies the $(L-1)$ token-stored minima $M_{Lh+j}, M_{Lh+h+j}, \dots, M_{Lh+(L-2)h+j}$ into fresh CLS slots $M'$. Because every input token $t \in [T]$ holds the identical value $c\tilde{z}_{i_2}(X_T)$ and CLS receives weight $\le e^{-\tilde{\beta}}$, ALL $D = (2L - 1)h$ minima arrive at CLS within $\delta + \frac{T}{e\tilde{\beta}} + 2e^{-\tilde{\beta}}$, with $\|x^{(\ell)}(s)\|_2 \le 1$ at every layer and $M = O_{d,L,h}(1/\epsilon^\gamma)$ **completely independent of $T$**. $\blacksquare$

*(Consistency remark: In the authors' empirical 2-layer NoPE experiment — Table 4 in arXiv v1, Table 5 in arXiv v2 / ICLR 2026 camera-ready — they tested $L = 2, D = 4$ with NoPE. Note that for $h = 1$, Theorem B achieves $(2L-1)h = 3 < 4$, while for $h = 2$, $Lh = 4 \le 6$; thus $D = 4$ happens not to fall strictly between $Lh$ and $(2L-1)h$ in the NoPE regime, though empirical training error does not directly test approximation capacity.)*
