Proofs, counterexamples, Python/Arb checks, and Lean 4 formalizations for 38 problems across machine learning, language models, neuroscience, neural coding, information theory, biology, and biophysics.

All 37 Lean modules compile with Lean `v4.24.0` + Mathlib, zero `sorry`s, zero compiler warnings, and standard axioms only (`propext`, `Classical.choice`, `Quot.sound`) across all 502 audited main theorems.

## Reproducing

### Lean 4
```bash
cd lean_proofs
lake exe cache get
lake build Conjectures
```
[`lean_proofs/Conjectures.lean`](lean_proofs/Conjectures.lean) imports all 37 modules and prints the axioms for all 502 audited main theorems. Each `.lean` file header documents exactly what is machine-checked vs. prose-only.

for f in solutions/*/explore.py solutions/*/verify_*.py; do
  python "$f"
